# DMS plugin registry

Plugins by Raimond Dumea for [DankMaterialShell](https://danklinux.com).

To use it, open **Settings → Plugins → Registries** in DMS, add the name
`ridumea` and the URL `https://github.com/ridumea/dms-registry.git`,
then install plugins from **Browse**.

| Plugin | |
|---|---|
| [Marina Dock](https://github.com/ridumea/dms-marina-dock) | A dock for niri that mirrors your layout |
